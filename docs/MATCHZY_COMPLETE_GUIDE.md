# MatchZy — Исчерпывающая энциклопедия и руководство на 100%

> **MatchZy** (автор: Shobhit Pathak / WD-) — это флагманский турнирный и соревновательный плагин для **Counter-Strike 2**, созданный на базе **CounterStrikeSharp** (.NET 10 / Metamod:Source). Является современным преемником легендарного плагина **Get5** для CS:GO, полностью наследуя и расширяя его стандарты, систему событий, REST/Webhook API и форматы JSON-конфигураций.

## 1. Архитектура, требования и окружение

### Технические требования
* **Движок**: Counter-Strike 2 Dedicated Server (`cs2.exe` / `cs2.sh`, Steam AppID `730`).
* **Модификатор движка**: **Metamod:Source v2.x** (ветка dev для CS2).
  * **КРИТИЧЕСКИ ВАЖНО**: В файле `game/csgo/gameinfo.gi` в блоке `FileSystem` ➔ `SearchPaths` **ОБЯЗАНА** присутствовать строка:
    ```kv
    Game    csgo/addons/metamod
    ```
    *(Строка с префиксом `Game_LowViolence` работать НЕ будет, так как движок активирует её только в китайском режиме цензуры `-perfectworld`)*.
* **Фреймворк**: **CounterStrikeSharp (CSS)** версии **v369+** (начиная с релиза v0.9.0 MatchZy собран под **.NET 10 runtime**).
* **Параметры запуска CS2**:
  ```bash
  -dedicated -console -port 27015 +ip 0.0.0.0 +map de_dust2 +maxplayers 12 -insecure -usercon +rcon_password "SECRET"
  ```
  *(Флаг `-insecure` обязателен для загрузки сторонних серверных DLL плагинов через Metamod)*.

### Структура каталогов MatchZy
```
game/csgo/
├── addons/
│   ├── metamod/
│   │   ├── counterstrikesharp.vdf      # Автозагрузчик CSS для Metamod
│   │   └── bin/win64/server.dll        # Metamod core
│   └── counterstrikesharp/
│       ├── gamedata/matchzy.json       # Оффсеты и сигнатуры функций CS2
│       └── plugins/MatchZy/

├── cfg/MatchZy/

│   ├── admins.json                     # Список администраторов с флагами прав
```

## 2. Полный формат Match Config (JSON Спецификация)

MatchZy загружает матчи двумя путями:
1. Локальный файл: `matchzy_loadmatch <относительный_путь_от_csgo>`
2. Удаленный URL: `matchzy_loadmatch_url "<URL>" "[Header-Key]" "[Header-Value]"`

```json
    "de_inferno"

  "veto_first": "team1",
  "side_type": "standard",
  "map_sides": [
    "knife"
  ],
  "clinch_series": true,
  "players_per_team": 5,
  "min_players_to_ready": 5,
  "min_spectators_to_ready": 0,
  "wingman": false,
  "scrim": false,
  "team1": {
    "name": "Natus Vincere",
    "tag": "NAVI",
    "flag": "UA",
    "logo": "navi",
    "players": {
      "76561198034202275": "s1mple",

      "76561197990682262",
```

### Подробное описание полей:

| Поле | Тип | Обязательное | Описание |
|---|---|:---:|---|
| `maplist` | `Array<string>` | **Да** | Список доступных или играемых карт (`de_dust2`, `de_mirage`, `de_inferno`...). Должен содержать минимум 1 карту. |
| `num_maps` | `int` | **Да** | Количество играемых карт в серии: `1` для BO1, `3` для BO3, `5` для BO5. Должно быть `<= maplist.length`. |
| `team1`, `team2` | `Object` | **Да** | Структура команды. Должна содержать `name` и `players`. |
| `team.players` | `Object` или `Array` | **Да** | Ростер команды. Поддерживает как объект `{ "SteamID64": "Никнейм" }`, так и простой массив `[ "SteamID64", ... ]`. При передаче объекта никнейм игрока фиксируется на сервере. |
| `matchid` | `int/long` | Нет | Уникальный ID матча (от 0 до `2147483647`). Если не передан, генерируется плагином автоматически. |
| `skip_veto` | `bool` | Нет | `true` — карты играются строго по списку `maplist` без драфта; `false` — если карт в `maplist` больше чем `num_maps`, запускается стадия Veto (баны/пики). |
| `veto_first` | `string` | Нет | Кто начинает veto: `"team1"`, `"team2"` или `"random"`. |
| `veto_mode` | `Array<string>` | Нет | Ручной порядок фаз вето: `["team1_ban", "team2_ban", "team1_pick", "team2_pick"]`. |
| `side_type` | `string` | Нет | Как выбираются стороны: `"standard"` (ножевой раунд), `"always_knife"`, `"never_knife"`, `"random"`. |
| `map_sides` | `Array<string>` | Нет | Точные стороны для каждой карты: `"team1_ct"`, `"team1_t"`, `"team2_ct"`, `"team2_t"`, `"knife"`. |
| `clinch_series` | `bool` | Нет | `true` (по умолчанию) — досрочно завершать серию, когда победитель набрал большинство карт (например, 2 победы в BO3). `false` — играть все карты. |
| `players_per_team` | `int` | Нет | Количество игроков в команде (по умолчанию `5`, для Wingman `2`, для дуэлей `1`). |
| `min_players_to_ready` | `int` | Нет | Минимальное число готовых игроков в команде для запуска (тренеры не учитываются). |
| `min_spectators_to_ready`| `int` | Нет | Требовать ли готовности спектаторов (по умолчанию `0`). |
| `wingman` | `bool` | Нет | Если `true`, активирует режим Напарников и загружает `live_wingman.cfg`. |
| `scrim` | `bool` | Нет | Тренировочный матч (скрим). |
| `spectators` | `Object` | Нет | Список наблюдателей по SteamID64. |
| `cvars` | `Object` | Нет | Словарь серверных переменных для данного матча. При завершении серии сбрасываются в исходные. |

> **Безопасность блока `cvars`**: В целях безопасности MatchZy блокирует выполнение любых произвольных команд (`quit`, `exec`, `rcon_password`, `matchzy_everyone_is_admin`). Разрешены только валидные ConVars движка и самого MatchZy.

## 3. Система ConVars (CVARs) — Полный реестр настроек

Файл `csgo/cfg/MatchZy/config.cfg` выполняется при старте плагина. Любую из этих переменных можно также переопределить динамически в блоке `cvars` JSON-конфига матча.

### 1. Управление матчем и готовностью:
* `matchzy_autostart_mode` (по умолчанию: `1`):
  * `0` — ничего не делать при запуске;
  * `1` — режим матча (Match mode);
  * `2` — тренировочный режим (Practice mode).
* `matchzy_ready_mode` (по умолчанию: `0`):
  * `0` — игроки обязаны писать `.ready` / `!ready` в чат;
  * `1` — **АВТО-ГОТОВНОСТЬ ПРИ ВХОДЕ**: как только нужное число игроков (`min_players_to_ready`) зашло за команду, команда автоматически считается готовой! Через `matchzy_join_start_delay` секунд матч стартует сам.
* `matchzy_join_start_delay` (по умолчанию: `10`):
  * Задержка (в секундах) перед автостартом матча после захода всех игроков (при `matchzy_ready_mode 1`).
* `matchzy_time_to_start` (по умолчанию: `0`):
  * Таймер разминки/ожидания готовности в секундах (аналог `get5_time_to_start`). Если время вышло, не готовой команде засчитывается техническое поражение (**forfeit**). `0` — без ограничения.
* `matchzy_time_to_start_veto` (по умолчанию: `0`):
  * Время на готовность к драфту карт. `0` — без ограничения.
* `matchzy_minimum_ready_required` (по умолчанию: `2`):
  * Минимальное количество готовых игроков для ручного режима (вне JSON-конфига). `0` — все присутствующие.
* `matchzy_allow_force_ready` (по умолчанию: `true`):
  * Разрешена ли игрокам команда `.forceready` для принудительной готовности своей команды.
* `matchzy_kick_when_no_match_loaded` (по умолчанию: `false`):
  * Кикать ли с сервера игроков, если матч не был загружен через JSON/URL.
* `matchzy_whitelist_enabled_default` (по умолчанию: `false`):
  * Включен ли вайтлист по умолчанию.

### 2. Ножевой раунд и стороны:
* `matchzy_knife_enabled_default` (по умолчанию: `true`):
  * Включен ли ножевой раунд за выбор стороны.
* `matchzy_playout_enabled_default` (по умолчанию: `false`):
  * Играть ли все 24 раунда независимо от досрочной победы 13 раундов (полезно для клубных скримов).

### 3. Паузы и откат:
* `matchzy_use_pause_command_for_tactical_pause` (по умолчанию: `false`):
  * `false` — `.pause` ставит стандартную техническую паузу; `true` — `.pause` тратит тактический таймаут команды (`.tac`).
* `matchzy_enable_tech_pause` (по умолчанию: `true`):
  * Разрешена ли игрокам команда `.tech`.
* `matchzy_tech_pause_flag` (по умолчанию: `""`):
  * CSS-флаг доступа для вызова технической паузы (пусто — доступно всем).
* `matchzy_max_tech_pauses` (по умолчанию: `0`):
  * Лимит технических пауз на команду за карту (`0` — без лимита).
* `matchzy_tech_pause_time` (по умолчанию: `0`):
  * Сколько секунд должна длиться техпауза, прежде чем любая ОДНА команда сможет ее снять. `0` — снять можно только при согласии обеих команд (`.unpause`).
* `matchzy_stop_command_available` (по умолчанию: `false`):
  * Доступна ли игрокам команда `.stop` для отката текущего раунда.
* `matchzy_stop_command_no_damage` (по умолчанию: `false`):
  * Запрещать ли `.stop`, если в раунде уже был нанесен урон сопернику.
* `matchzy_pause_after_restore` (по умолчанию: `true`):
  * Ставить ли автоматическую паузу после восстановления раунда из бэкапа.

### 4. Вебхуки и логирование:
* `matchzy_remote_log_url` (по умолчанию: `""`):
  * **URL для отправки всех JSON событий** матча через HTTP POST (наш эндпоинт в DashAdmin).
* `matchzy_remote_log_header_key` (по умолчанию: `""`):
  * Имя HTTP-заголовка авторизации (`Authorization` / `X-Club-Token`).
* `matchzy_remote_log_header_value` (по умолчанию: `""`):
  * Значение токена авторизации.

### 5. Демки (GOTV) и Бэкапы:
* `matchzy_demo_recording_enabled` (по умолчанию: `true`):
  * Автоматическая запись GOTV демок.
* `matchzy_demo_path` (по умолчанию: `"MatchZy/"`):
  * Каталог внутри `csgo/` для сохранения файлов `.dem`.
* `matchzy_demo_name_format` (по умолчанию: `"{TIME}_{MATCH_ID}_{MAP}_{TEAM1}_vs_{TEAM2}"`):
  * Шаблон имени файла демки.
* `matchzy_demo_upload_url` (по умолчанию: `""`):
  * URL, куда автоматически загружается готовая сжатая демка после окончания карты.
* `matchzy_remote_backup_url` (по умолчанию: `""`):
  * URL, куда отправляются дампы раундов по HTTP POST.

### 6. Визуальные и чат настройки:
* `matchzy_chat_prefix` (по умолчанию: `[{Green}MatchZy{Default}]`):
  * Префикс сообщений плагина.
* `matchzy_admin_chat_prefix` (по умолчанию: `[{Red}ADMIN{Default}]`):
  * Префикс сообщений админа (`.asay`).
* `matchzy_hostname_format` (по умолчанию: `"MatchZy | {TEAM1} vs {TEAM2}"`):
  * Формат имени сервера в браузере CS2 (переменные: `{TIME}`, `{MATCH_ID}`, `{MAP}`, `{TEAM1}`, `{TEAM2}`, `{TEAM1_SCORE}`, `{TEAM2_SCORE}`).
* `matchzy_enable_damage_report` (по умолчанию: `true`):
  * Вывод отчета об уроне в чат игрокам после завершения раунда.
* `matchzy_smoke_color_enabled` (по умолчанию: `false`):
  * Окрашивание смоков в цвет команды игрока.

## 4. Команды управления: Консольные, RCON, Админские и Игровые

Все команды чата могут вводиться как с точкой (`.ready`), так и с восклицательным знаком (`!ready`). Консольные команды CounterStrikeSharp имеют префикс `css_`.

### 1. Администраторские команды (RCON / Чат):
| Чат команда | Консольная / RCON команда | Описание |
|---|---|---|
| `.start` | `css_start` / `css_forcestart` | Принудительный старт матча (игнорируя готовность игроков). |
| `.restart` / `.rr` | `css_restart` / `css_rr` | Сброс и перезапуск текущего матча. |
| `.endmatch` | `css_endmatch` / `get5_endmatch` | Завершить/отменить матч без победителя. |
| `.endmatch team1` | `get5_endmatch team1` | Завершить матч с досрочной победой Team 1. |
| `.endmatch team2` | `get5_endmatch team2` | Завершить матч с досрочной победой Team 2. |
| `.forcepause` / `.fp` | `css_forcepause` / `css_fp` | Поставить паузу от имени администратора (игроки не могут снять). |
| `.forceunpause` / `.fup` | `css_forceunpause` / `css_fup` | Снять любую паузу от имени администратора. |
| `.restore <раунд>` | `css_restore <раунд>` | **Откатить матч к началу раунда №X** (например: `.restore 7`). |
| `.roundknife` / `.rk` | `css_roundknife` / `css_rk` | Переключить ножевой раунд (вкл/выкл). |
| `.playout` | `css_playout` | Переключить режим Playout (играть все раунды). |
| `.whitelist` / `.wl` | `css_whitelist` / `css_wl` | Включить/выключить проверку белого списка игроков. |
| `.readyrequired <число>`| `css_readyrequired <число>` | Задать число игроков, требуемых для готовности. |
| `.addreadytime <сек>` | `matchzy_add_ready_time <сек>` | Добавить командам дополнительное время на разминку. |
| `.map <карта>` | `css_map <карта>` | Сменить карту на сервере (`changelevel`). |
| `.asay <текст>` | `css_asay <текст>` | Сообщение от имени администратора всем игрокам. |
| `.reload_admins` | `reload_admins` | Перезагрузить список администраторов из `admins.json`. |
| `.team1 <название>` | `css_team1 <название>` | Задать имя Команде 1 (CT по умолчанию). |
| `.team2 <название>` | `css_team2 <название>` | Задать имя Команде 2 (T по умолчанию). |
| `.skipveto` / `.sv` | `css_skipveto` / `css_sv` | Пропустить стадию драфта карт (Veto). |
| `.settings` | `css_settings` | Показать текущие параметры матча в чате. |
| `.prac` | `css_prac` | Включить тренировочный режим (Practice). |
| `.exitprac` / `.match` | `css_exitprac` / `css_match` | Выйти из тренировочного режима и вернуться в матч. |
| `.rcon <команда>` | `css_rcon <команда>` | Выполнить консольную команду сервера. |

### 2. Игровые команды (Чат):
| Команда | Алиасы | Описание |
|---|---|---|
| `.ready` | `.r` | Подтвердить готовность к игре. |
| `.unready` | `.ur`, `.notready` | Отменить готовность. |
| `.forceready` | — | Капитан/игрок делает всю свою команду готовой. |
| `.pause` | — | Поставить техническую паузу (или тактический таймаут). |
| `.tech` | — | Поставить техническую паузу. |
| `.unpause` | — | Запросить снятие паузы (обе команды должны ввести `.unpause`). |
| `.stay` | — | Остаться за текущую сторону (после победы на ножах). |
| `.switch` | `.swap` | Перейти за противоположную сторону (после победы на ножах). |
| `.stop` | — | Голосование за откат текущего раунда (нужно подтверждение обеих команд). |

| `.coach <сторона>`| — | Сесть на слот тренера: `.coach ct` или `.coach t`. |
| `.uncoach` | — | Покинуть слот тренера. |

## 5. Разминка (Warmup), Готовность (Ready) и Автостарт

MatchZy полностью управляет фазой разминки через `cfg/MatchZy/warmup.cfg`:
* По умолчанию таймер CS2 заблокирован: `mp_warmup_pausetimer 1` и `mp_warmuptime 9999`.

### 3 стратегии проведения разминки в DashAdmin:

1. **Стратегия «Соревновательный автостарт» (`matchzy_ready_mode 1`)**:
   * В блоке `cvars` передаем:
     ```json
     "matchzy_ready_mode": "1",
     "matchzy_join_start_delay": "10",
     "matchzy_time_to_start": "180"
     ```
   * **Как работает**: Игрокам вообще **не нужно** писать `.ready`. Сервер отслеживает подключение игроков. Как только составы 5v5 или 2v2 укомплектованы, включается обратный отсчет 10 секунд, и матч стартует сам! Если команда не собралась за 180 секунд — ей засчитывается поражение.

2. **Стратегия «Классическая готовность» (`matchzy_ready_mode 0`)**:
   * Игроки разминаются, закупаются оружием.
   * Каждый игрок пишет `.ready` (или капитан пишет `.forceready`).
   * В веб-панели DashAdmin админ клуба видит, кто готов, и может в один клик нажать кнопку **«Форсировать старт»** (`css_start`).

3. **Стратегия «Фиксированное время разминки»**:
   * Если клубу нужно строго 60 или 120 секунд разминки без кнопок готовности:
     ```json
     "cvars": {
       "mp_warmup_pausetimer": "0",
       "mp_warmuptime": "60"
     }
     ```

## 6. Ножевой раунд (Knife Round) и выбор стороны

1. **Фаза Knife Round**:
   * Активируется конфиг `cfg/MatchZy/knife.cfg`: броня 100%, оружие изъято, только ножи и кевлар, отсутствие денег, время раунда 1.92 мин.
2. **Определение победителя**:
   * При гибели последней стороны плагин фиксирует команду-победителя (`knifeWinner`).
3. **Выбор стороны**:
   * В чате появляется уведомление: победитель должен написать `.stay` (остаться) или `.switch` (поменяться).
   * Если победители в течение 30 секунд ничего не выбрали, стороны остаются прежними по умолчанию.
4. **Переход в Live**:
   * При `.switch` MatchZy выполняет `mp_swapteams 1`, делает перезапуск `mp_restartgame 1` и начинает матч!

## 7. Паузы: Тактические (Tac) и Технические (Tech)

MatchZy имеет самую надежную реализацию пауз в CS2, избегающую багов зависания раундов:
* **Тактический таймаут (`.tac`)**:
  * Расходует встроенные игровые таймауты Valve (`timeout_ct_start` / `timeout_terrorist_start`).
  * Пауза длится фиксированные 30 секунд в FreezeTime, замораживая таймер покупки.
* **Техническая пауза (`.tech` / `.pause`)**:
  * Замораживает раунд в ближайший FreezeTime.
  * Для снятия паузы обе команды должны написать `.unpause`.
  * Администратор может снять паузу в любой момент командой `.forceunpause` (`css_fup`).
  * В конфиге можно настроить `matchzy_tech_pause_time 60` — через 60 секунд любая команда сможет снять паузу в одиночку.

## 8. Система бэкапов и отката раундов (Round Restore)

MatchZy сохраняет полное состояние игры в начале каждого раунда в папку `game/csgo/MatchZyDataBackup/`.

### Формат файлов бэкапа:
* `matchzy_<matchid>_<mapnumber>_round<XX>.json` — служебный снимок состояния MatchZy (счет, игроки, тренеры, фраги).
* `matchzy_<matchid>_<mapnumber>_round<XX>.cfg` — движковый снимок Valve (деньги каждого игрока, инвентарь, броня, позиции).

### Как откатить раунд:
1. **Через RCON или веб-панель DashAdmin**:
   ```bash
   css_restore 5
   ```
   *Матч мгновенно откатится к началу 5-го раунда, восстановит точный счет, баланс денег и закупку каждого игрока на тот момент, и поставит игру на паузу.*
2. **Через голосование игроков**:
   * Обе команды пишут `.stop` в чат. Раунд мгновенно перезапускается с начала.
3. **Восстановление после падения сервера**:
   * Если сервер CS2 перезагрузился посреди матча, MatchZy автоматически загрузит последний бэкап текущего матча командой:
     ```bash
     matchzy_loadbackup matchzy_10542_0_round08.json
     ```

## 9. Система тренерства (Coaching System)

MatchZy включает встроенный менеджер тренеров для CS2:
* Чтобы стать тренером команды, игрок заходит на сервер в спектаторы и пишет:
  * `.coach ct` — стать тренером CT.
  * `.coach t` — стать тренером Terrorist.
* **Механика**:
  * Тренер привязывается к команде, получает клантег `[TEAM COACH]`.
  * Плагин автоматически телепортирует тренера на специальную позицию тренера за спинами игроков на спавне.
  * Тренер видит только камеры и экран игроков своей команды и слышит их голосовой чат.
  * Для выхода из режима тренера используется команда `.uncoach`.

## 10. GOTV Запись и автоматическая выгрузка демок

### Автоматическая запись:
* MatchZy сам стартует запись GOTV сразу после перехода в Live (после ножевого раунда) с помощью `tv_record`.
* Запись гарантированно защищена от обрыва при перезапуске раунда благодаря отложенному старту `StartDemoRecordingAfterRestart`.

### Автоматическая выгрузка на бэкенд:
В конфиге матча задается:
```json
"cvars": {
  "matchzy_demo_upload_url": "https://mydashadmin.ru/api/clubs/1/cs2/demos/upload",
  "matchzy_demo_upload_header_key": "Authorization",
  "matchzy_demo_upload_header_value": "Bearer CLUB_SECRET_TOKEN"
}
```
* После окончания карты MatchZy ожидает `tv_delay` (чтобы телетрансляция завершилась), останавливает запись, сжимает файл в `.zip` и отправляет стримом через HTTP POST.
* **HTTP заголовки запроса**:
  * `MatchZy-FileName`: имя файла (например, `20261005_10542_de_dust2_NAVI_vs_FaZe.dem.zip`).
  * `MatchZy-MatchId`: идентификатор матча.
  * `MatchZy-MapNumber`: индекс карты в серии.

## 11. Система Webhook-событий (HTTP Event Logging)

MatchZy отправляет все игровые события в реальном времени на URL, указанный в `matchzy_remote_log_url`.

### Типы событий (`event`):
1. `series_start` — старт серии (команды, число карт).
2. `going_live` — окончание разминки/ножевого и переход в боевой режим.
3. `round_start` — старт раунда (начало FreezeTime).
4. `player_death` — фраг (жертва, убийца, ассистент, оружие, хедшот, прострел сквозь дым/стену, ослепление).
5. `bomb_planted` — установка бомбы (игрок, плент A/B).
6. `bomb_defused` — разминирование бомбы (оставшееся время таймера).
7. `round_end` — конец раунда (победитель, причина победы, детальная статистика каждого игрока за раунд).
8. `game_paused` / `game_unpaused` — фиксация пауз (тип: `technical`, `admin`, `backup`).
9. `backup_loaded` — откат раунда (номер восстановленного раунда).
10. `player_disconnect` — отключение игрока во время официального матча.
11. `map_result` — завершение карты (победитель, итоговый счет, командная статистика).
12. `series_end` — окончание всего матча/серии (победитель серии, финальный счет карт).
13. `demo_upload_ended` — статус отправки демки на сервер (`success: true/false`).

### Пример полезной нагрузки события `round_end`:
```json
{
  "event": "round_end",
  "matchid": 10542,
  "map_number": 0,
  "round_number": 4,
  "round_time": 115200,
  "reason": 1,
  "winner": {
    "side": "ct",
    "team": "team1"
  },
  "team1": {
    "score": 3,
    "consecutive_round_losses": 0,
    "timeouts": 3
  },
  "team2": {
    "score": 1,
    "consecutive_round_losses": 1,
    "timeouts": 4
  }
}
```

## 12. База данных и сбор детальной статистики игроков

MatchZy ведет собственный учет статистики в базе данных SQLite (`csgo/cfg/MatchZy/matchzy.db`) или внешней MySQL.

### Таблица `matchzy_stats_players`:
Фиксирует свыше **30 ключевых параметров** каждого игрока:
* `kills`, `deaths`, `assists`, `damage` — базовые показатели.
* `head_shot_kills` — убийства в голову (для вычисления точного HS%).
* `utility_damage`, `enemies_flashed` — урон гранатами и число ослепленных врагов.
* `shots_fired_total`, `shots_on_target_total` — точность стрельбы (Accuracy).
* `entry_count`, `entry_wins` — дуэли первого контакта (First Blood / Entry Kill rate).
* `v1_count`, `v1_wins`, `v2_count`, `v2_wins` — статистика клатчей (1v1, 1v2).
* `enemy2ks`, `enemy3ks`, `enemy4ks`, `enemy5ks` — мультикиллы и эйсы (Aces).
* `cash_earned`, `equipment_value`, `money_saved` — экономическая эффективность.

После каждой карты отчет автоматически дублируется в CSV:
`csgo/MatchZy_Stats/match_data_map{mapNumber}_{matchId}.csv`.

## 13. Тренировочный режим (Practice Mode)

Для тренировки раскидок и тактик MatchZy имеет встроенный режим `.prac`.

### Основные команды:
* `.bot` / `.crouchbot` — поставить стоячего или присевшего бота на позицию прицела.
* `.boost` / `.crouchboost` — поставить бота под собой и подсадить игрока.
* `.savenade <имя>` / `.loadnade <имя>` — сохранить и загрузить гранату/раскидку в файл.
* `.rethrow` (`.rt`) — повторить бросок последней гранаты.
* `.delay <сек>` — задать задержку перед броском повторной гранаты.
* `.clear` — мгновенно убрать все дымы, огонь и молотовы на карте.
* `.god` — режим бессмертия.
* `.noflash` — иммунитет к ослеплению для тренирующегося.
* `.fastforward` (`.ff`) — перемотать время вперед на 20 секунд.
* `.spawn <номер>` — телепортироваться на соревновательный спавн.
* `.exitprac` — завершить тренировку и вернуться в режим матча.

## 14. Интеграция с DashAdmin & DashMatch (Best Practices)

### Полный жизненный цикл матча в клубе:
```
1. Создание матча в DashAdmin:
   └── POST /api/clubs/[clubId]/cs2/matches
       └── Формируется config_data (JSON) со SteamID64 игроков из биллинга.

2. Запуск через DashMatch Agent:
   └── DashMatch выделяет свободный порт (27015), запускает cs2.exe с -insecure.
   └── Перед стартом автоматически проверяет и правит gameinfo.gi (Metamod hook).
   └── Ожидает сокет RCON (до 90 секунд).

3. Передача конфигурации:
   └── RCON: matchzy_loadmatch_url "https://mydashadmin.ru/api/clubs/1/cs2/matches/xxx/config"

4. Фаза разминки и игра:
   └── При matchzy_ready_mode 1 игроки садятся за ПК в клубе, коннектятся к LAN IP сервера.
   └── Как только 10 человек зашли — через 10 секунд стартует ножевой раунд!
   └── Победитель ножей пишет .stay или .switch.
   └── Начинается официальный Live (MR12).

5. Управление из дашборда клуба в реальном времени:
   └── Вкладка «Игроки»: перенос игроков между командами через css_addplayer.
   └── Вкладка «Управление»: откат раунда через css_restore <N>.
   └── Вкладка «Консоль»: отправка любых команд (get5_status, status, mp_swapteams).

6. Автоматическое завершение:
   └── При победе одной из команд MatchZy шлет webhook 'series_end'.
   └── DashAdmin пересчитывает ELO, начисляет клубные баллы/фраги.
   └── DashMatch останавливает процесс cs2.exe и освобождает порт.
```

Благодаря этой связке вся инфраструктура CS2 в компьютерном клубе работает на 100% автономно, надежно и на профессиональном киберспортивном уровне!
