# Спецификация: Модуль автоматизации маркетинга, задач и кампаний (Marketing Automation & CRM)

## 1. Цели и назначение
Превращение аналитических данных маркетинга (статусы оттока, киты, балансы, любимые ПК, дни и зоны) в действующие бизнес-процессы:
1. **Персональные задачи для администраторов** (вкладка «Задачи»): генерация точечных заданий на бронь и звонки постоянникам и китам с готовым скриптом.
2. **SMS-кампании с кастомизацией шаблонов**: конструктор шаблонов с тегами (`{Имя}`, `{Баланс_Руб}`, `{Баланс_Бонус}`, `{Любимый_ПК}`, `{Любимый_День}`, `{Любимый_Тариф}`, `{Любимая_Зона}`) + экспорт в CSV/Excel для SMS-шлюзов (с заделом под прямой API).
3. **VK Реклама**: сегментированный экспорт аудиторий для `ads.vk.com` (Киты для Lookalike, Отток, PS Зона, Ночники, Выходные $\rightarrow$ Будни).
4. **Настройки и черный список исключений**: список номеров-исключений (админы, владелец, сотрудники), которые автоматически отфильтровываются из всех сегментов, задач и рассылок.
5. **Сквозная аналитика и отслеживание возврата**: фиксация запущенных кампаний и автоматическая сверка с последующими загрузками отчетов/сессий (кто из таргетированных клиентов вернулся, сколько принес в кассу, подсвечивание в таблице бейджем `🎯 Вернулся`).

## 2. Архитектура и компоненты

### 2.1. Вкладка «Задачи» (`TasksTab.tsx`)
- Список задач на смену:
  - Клиент (ФИО, телефон, статус, сумма трат).
  - Тип задачи: *VIP-бронь на опережение*, *Возврат засыпающего постоянника*, *Консьерж-сервис*.
  - Персональный скрипт для администратора (с подставленными ПК, временем и днем).
  - Действия: `[✓ Выполнено / Забронировал]`, `[📞 Не дозвонился]`, `[✕ Отказ]`.
  - Фильтры по статусу задач: *К выполнению*, *Завершенные*, *Отложенные*.
  - Кнопка *«Сгенерировать задачи из китов и постоянников»*.

### 2.2. Конструктор SMS и шаблонов (`SmsCampaignModal.tsx` / `CampaignsManager`)
- Выбор когорты (например: *Засыпающие с балансом > 150 ₽*, *Киты*, *Отток 30–60 дней*).
- Поле шаблона сообщения с кликабельными тегами:
  - `{Имя}` $\rightarrow$ имя гостя (или "Гость").
  - `{Баланс_Руб}` $\rightarrow$ баланс рублей на аккаунте.
  - `{Баланс_Бонус}` $\rightarrow$ бонусный баланс.
  - `{Любимый_ПК}` $\rightarrow$ любимый номер компьютера.
  - `{Любимый_День}` $\rightarrow$ день недели (например, "четверг").
  - `{Любимый_Тариф}` $\rightarrow$ любимый тариф.
  - `{Любимая_Зона}` $\rightarrow$ любимая зона.
- Интерактивный предпросмотр (Live Preview) на реальном примере из базы.
- Расчет стоимости рассылки (кол-во SMS $\times$ 3.5 ₽).
- Кнопка выгрузки в CSV/Excel + сохранение кампании для сквозного отслеживания.

### 2.3. Экспорт для VK Таргета (`VkAudiencesModal.tsx`)
- 5 готовых пресетов аудиторий:
  1. *Киты для Look-a-like* (топ по LTV)
  2. *Реактивация оттока* (30–90 дней)
  3. *Консольщики (PS Зона)*
  4. *Ночники (Пакет Ночь)*
  5. *Игроки выходных дней*
- Скачивание чистого списка номеров телефонов в формате `+7XXXXXXXXXX` под требования `ads.vk.com`.
- Фиксация кампании в реестре для трекинга.

### 2.4. Настройки и номера-исключения (`MarketingSettingsModal.tsx`)
- Список номеров телефонов, исключенных из маркетинга (владелец, управляющий, админы, техперсонал).
- Сохранение в базе данных / локальном хранилище клуба.
- Автоматическая фильтрация этих номеров из всех срезов, рассылок, задач и списков клиентов.

### 2.5. Сквозная аналитика и трекинг возврата
- Модель кампании (`marketing_campaigns` / сохраненное состояние):
  - ID, название, канал (Задачи / SMS / VK), дата запуска, список целевых номеров телефонов.
- При загрузке новых отчетов или при просмотре среза:
  - Сверка телефонов из кампании с датами визитов.
  - Подсчет метрик: `Отправлено`, `Вернулись (чел / %)`, `Выручка от вернувшихся (₽)`.
  - В таблице гостей бейдж: `🎯 Вернулся по кампании [Название]`.

export interface MarketingTask {
  id: string;

  phone: string;
  clientName: string;
  type: "whale_booking" | "churn_prevent" | "balance_reminder" | "custom";
  title: string;
  script: string;
  status: "pending" | "completed" | "no_answer" | "rejected";
  dueDate?: string;
  completedAt?: string;
  adminNote?: string;
  createdAt: string;
}

export interface MarketingCampaign {
  id: string;
  clubId: string;
  name: string;
  channel: "tasks" | "sms" | "vk";
  templateText?: string;
  targetPhones: string[];
  createdAt: string;

  returnedCount?: number;
  returnedRevenue?: number;
}

  excludedPhones: string[];
}
