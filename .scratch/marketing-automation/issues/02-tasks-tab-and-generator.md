# Ticket 02: Вкладка «Задачи» и генератор персональных заданий смене

Status: ready-for-agent
Blocked by: 01

## Описание
Реализовать отдельную вкладку «Задачи» (`TasksTab.tsx`) в навигации маркетинга. Генерация персональных заданий администраторам с готовыми скриптами звонков/сообщений на основе данных о любимом дне, любимом ПК и тарифе китов и постоянников.

## Критерии приемки
1. Добавить вкладку «Задачи» рядом с «Аналитика», «Сегменты», «Оборудование», «Удержание клиентов», «Загрузка отчетов».
2. Генератор задач:
   - *VIP-бронь на опережение*: для Китов (Whales), у которых приближается их `favoriteDay`. Скрипт подставляет имя, ПК (`favoriteSeat`), тариф (`favoriteTariff`) и день недели.
   - *Предотвращение оттока*: для засыпающих постоянников (не были 14–25 дней).
   - *Забытый баланс*: для клиентов с балансом > 300 ₽, которые давно не заходили.
3. Карточки задач в интерфейсе с бейджами приоритета, кнопкой копирования текста скрипта, кнопкой быстрого звонка / WhatsApp.
4. Кнопки статуса: `[✓ Забронировал]`, `[📞 Не дозвонился]`, `[✕ Отказ]`.
5. Фильтрация задач по статусам и счетчик невыполненных задач в бейдже вкладки.
6. Сохранение задач в `localStorage` по клубу (`marketing_tasks_${clubId}`).
