# Ticket 04: Экспорт сегментов для VK Рекламы (ads.vk.com)

Status: ready-for-agent
Blocked by: 01

## Описание
Создать модуль выгрузки сегментированных аудиторий для рекламного кабинета ВКонтакте (VK Ads / кабинет ретаргетинга) под 5 готовых стратегий.

## Критерии приемки
1. Модальное окно «Экспорт аудиторий для VK Рекламы».
2. 5 готовых пресетов:
   - *Киты (LTV 5000+ ₽)* — идеальная база для создания Look-a-like аудитории в VK.
   - *Отток за 30–90 дней* — кампания реактивации со спецпредложением.
   - *Любители PS Зоны* — реклама турниров по консольным играм (FC25, UFC).
   - *Ночники (Пакет Ночь)* — реклама ночных пакетов перед выходными.
   - *Игроки выходных* — оффер со скидками на будние дни (Вт–Ср).
3. Экспорт текстового файла `.txt`/`.csv` с чистыми номерами телефонов (один номер на строку, формат `79XXXXXXXXX` или `+79XXXXXXXXX` в соответствии с требованиями VK Ads).
4. Регистрация экспорта в реестре кампаний для последующего отслеживания возврата.
