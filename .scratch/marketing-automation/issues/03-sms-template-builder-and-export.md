# Ticket 03: Конструктор персональных SMS-шаблонов и экспорт для шлюзов

Status: ready-for-agent
Blocked by: 01

## Описание
Создать модальное окно / инструмент создания персональных SMS-рассылок с интерактивным конструктором шаблонов, динамическими тегами и экспортом в CSV/Excel для SMS-сервисов.

## Критерии приемки
1. Выбор сегмента получателей: *Забытый баланс (> 150 ₽)*, *Киты*, *Отток (не были > 30 дней)*, *Все с балансом*, *Выбранные клиенты*.
2. Редактор шаблона сообщения с кликабельными тегами-вставками:
   - `{Имя}`
   - `{Баланс_Руб}`
   - `{Баланс_Бонус}`
   - `{Любимый_ПК}`
   - `{Любимый_День}`
   - `{Любимый_Тариф}`
   - `{Любимая_Зона}`
3. Live Preview: показ того, как реальное сообщение будет выглядеть для первого клиента из выбранного списка.
4. Калькулятор символов, частей SMS и примерного бюджета (кол-во контактов × 3.5 ₽).
5. Экспорт в CSV/Excel со столбцами: `Телефон` (формат 79XXXXXXXXX) и `Текст сообщения`.
6. Сохранение созданной рассылки в реестр кампаний для сквозной аналитики.
